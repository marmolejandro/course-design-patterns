## Patrones de diseño

El código está escrito en TypeScript y usamos Deno para ejecutarlo, puedes usar Bun o Node si lo prefieres.

Si usas Node, deberás configurar TypeScript, por lo que te recomiendo Deno o Bun.


# Patrones Creacionales
Resuelven problemas relacionados con:
- ¿Cómo crear objetos de manera eficiente?
- Ocultar la lógica de instanciación.
- Reducir el acoplamiento de clases.

Las principales ventajas son:
- Reducción de código duplicado.
- Mayor claridad en el proceso de creación de objetos.
- Alineación con principios SOLID.
- Mejora la flexibilidad al cambiar el proceso de creación
- Promueve el principio de responsabilidad única.
